# Gx_Rajput — Packaging & Brand Identity Portfolio

A responsive, static portfolio for **Noor Ul Hassan (Gx_Rajput)**, an independent designer based in Pakistan and available to work worldwide.

- Live site: https://rajputbrothers8184.github.io/Gx_Rajput/
- Repository: https://github.com/Rajputbrothers8184/Gx_Rajput
- Stack: HTML, CSS and vanilla JavaScript. No build step or backend is required.

## Creative direction

The redesign positions Gx_Rajput around packaging design, product labels and brand identity, with an editorial visual system, warm neutral palette, oversized typography and original CSS-built packaging concept artwork.

## Portfolio concepts

The gallery includes six self-initiated concepts: Orova Botanicals (haircare), Nēma Skin (skincare), Vanta Form (sports nutrition), Forma Roasters (specialty coffee), Sōra Tea Co. (botanical tea), and Field Supply (personal care).

**Important:** These are illustrative, self-initiated portfolio concepts, not commissioned client projects or real product brands. Do not present them as client work.

## Features

- Responsive desktop and mobile layouts
- Category filters for beauty & care, wellness, and food & drink
- Project detail dialogs
- WhatsApp project enquiry and email contact links
- Search metadata, canonical URL and basic Person structured data
- Reduced-motion support and semantic page sections

## Before public launch

1. Confirm the service positioning and every public contact/social link.

3. Confirm all experience, client and performance claims before publishing them; no unsupported metrics are used in this redesign.
4. Add real project photography or refined final mockups as each concept is completed.
5. Connect and verify Google Search Console, submit the sitemap, and review indexing after deployment.
